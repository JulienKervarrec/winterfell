## Lire une trace dexecution

Winterfell represente le calcul sous forme de trace soumise a des contraintes. Ce chapitre explique comment les lignes, colonnes et bornes de la trace deviennent des engagements verifiables. La distinction entre execution et preuve permet de comprendre ou intervient chaque composant. Les noms sont derives de lorganisation du code source.
